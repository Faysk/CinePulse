# Hardware MegaPack H6 — physical acceptance

H6 must not be marked physically accepted from hosted CI. The GPU compositor may be used only after evidence is produced on the exact target machine and exact FFmpeg build.

## Reference contract

The authoritative visual baseline is `composer-numpy-rgba-v1`, generated by `export_composer_reference`. Older evidence generated against FFmpeg's software `overlay` filter is intentionally invalid and cannot authorize runtime use.

The initial CUDA envelope is deliberately narrow:

- one enabled media layer only;
- PNG, GIF, APNG, WebP or video-alpha input;
- normal alpha blend;
- scale exactly 1.0;
- no rotation or spin;
- no pulse or beat reaction;
- 8-bit SDR yuv420p base with explicit known color metadata;
- exact GPU name, NVIDIA driver, FFmpeg fingerprint, geometry, FPS, color profile and layer contract.

Multiple layers and procedural/audio-reactive visualizers remain on the NumPy reference until a shader backend proves project-level parity. Per-layer evidence must never be composed into an unmeasured multi-layer permission.

## Required command

Use the same cache path that the Preview runtime reads:

```powershell
python scripts/gpu_compositor_benchmark.py `
  --base C:\bench\base-1080p30.mkv `
  --layer C:\bench\overlay.png `
  --kind png `
  --cache "$env:LOCALAPPDATA\CinePulse\cache\hardware\gpu-compositor.json" `
  --duration 5
```

Repeat with representative layer types actually intended for use. A record is exact-key evidence, never a global RTX/GPU pass.

## Acceptance gates

A candidate is rejected unless all gates pass:

- speedup >= 1.03x against the actual NumPy/RGBA Composer reference;
- PSNR >= 80 dB;
- SSIM >= 0.999999;
- exact frame-count parity;
- output video metadata parity;
- alpha/composite parity;
- visual duration difference <= 20 ms;
- no audio is modified by the optimized boundary; production audio remains in the unchanged post-composition mux stage.

If `overlay_cuda` incurs chroma/alpha conversion loss and cannot meet these thresholds, that is a valid **REJECT**. The correct response is to keep the CPU reference and investigate a higher-fidelity GPU shader/RGBA path, not lower the quality threshold.

## Runtime failure rule

When a future runtime fast path is enabled, any CUDA error, incomplete output, metadata mismatch or integrity failure must invalidate the exact evidence record and retry the job through the CPU reference. It must never silently continue with a partially rendered GPU output.

## Still pending

Hosted CI proves schema, routing, fallback semantics and benchmark construction only. RTX 4070 utilization, visual parity, sustained thermals, 8K/120 throughput and actual CUDA compositor speed remain pending physical execution.
