# Hardware MegaPack H6 — physical acceptance

H6 must not be marked physically accepted from hosted CI. The GPU compositor may be used only after evidence is produced on the exact target machine and exact FFmpeg build.

## Reference contract

The authoritative visual baseline is `composer-numpy-rgba-v1`, generated by `export_composer_reference`. Older evidence generated against FFmpeg's software `overlay` filter, or against H6 schema 2 single-layer records, is intentionally invalid and cannot authorize runtime use.

The current CUDA benchmark envelope is deliberately narrow:

- one to four enabled media layers as one exact ordered stack;
- PNG, GIF, APNG, WebP or video-alpha input;
- normal alpha blend for every member;
- scale exactly 1.0;
- no rotation or spin;
- no pulse or beat reaction;
- 8-bit SDR yuv420p base with explicit known color metadata;
- exact GPU name, NVIDIA driver, FFmpeg fingerprint, geometry, FPS, color profile and **whole-stack** contract.

The stack is canonicalized by z-order, stays on CUDA surfaces between `overlay_cuda` stages, and is downloaded once after the last overlay. The evidence key hashes every layer and its ordered controls. Individual layer evidence can never be combined transitively to unlock a multi-layer project: alpha rounding and ordering are measured for the complete stack.

Procedural/audio-reactive visualizers, arbitrary rotation/scaling and non-normal blends remain on the NumPy reference until a suitable shader backend proves project-level parity.

## Required commands

Use the same cache path that the Preview runtime reads. Legacy one-layer acceptance remains available:

```powershell
python scripts/gpu_compositor_benchmark.py `
  --base C:\bench\base-1080p30.mkv `
  --layer C:\bench\overlay.png `
  --kind png `
  --cache "$env:LOCALAPPDATA\CinePulse\cache\hardware\gpu-compositor.json" `
  --duration 5
```

For the production stack envelope, create a manifest such as:

```json
{
  "layers": [
    {"source": "logo.png", "kind": "png", "x": 0.15, "y": 0.15, "opacity": 0.9, "z_order": 10},
    {"source": "frame.webp", "kind": "webp", "x": 0.5, "y": 0.5, "opacity": 1.0, "z_order": 20}
  ]
}
```

Then run:

```powershell
python scripts/gpu_compositor_benchmark.py `
  --base C:\bench\base-1080p30.mkv `
  --stack-manifest C:\bench\h6-stack.json `
  --cache "$env:LOCALAPPDATA\CinePulse\cache\hardware\gpu-compositor.json" `
  --duration 5
```

Relative media paths in the manifest resolve from the manifest directory. The benchmark rejects stacks larger than four layers or any member outside the static normal-blend envelope. A record is exact-key evidence, never a global RTX/GPU pass.

## Acceptance gates

A candidate is rejected unless all gates pass:

- speedup >= 1.03x against the actual NumPy/RGBA Composer reference;
- PSNR >= 80 dB;
- SSIM >= 0.999999;
- exact frame-count parity;
- output video metadata parity;
- alpha/composite parity for the complete ordered stack;
- visual duration difference <= 20 ms;
- no audio is modified by the optimized boundary; production audio remains in the unchanged post-composition mux stage.

If `overlay_cuda` incurs chroma/alpha conversion loss and cannot meet these thresholds, that is a valid **REJECT**. The correct response is to keep the CPU reference and investigate a higher-fidelity GPU shader/RGBA path, not lower the quality threshold.

## Runtime failure rule

Preview desktop export now routes through `export_composer_auto`. It may enter CUDA only when the exact whole-stack record above is present and current. Any CUDA/process/integrity failure invalidates only that exact evidence key and retries once through `export_composer_reference`. Cancellation never invalidates evidence and never silently restarts the render through another backend.

The output remains atomic: a failed/cancelled GPU attempt cannot replace a previously good destination.

## Still pending

Hosted CI proves schema, ordered-stack routing, rollback semantics and benchmark construction only. RTX 4070 utilization, visual parity, sustained thermals, 8K/120 throughput and actual CUDA compositor speed remain pending physical execution.
